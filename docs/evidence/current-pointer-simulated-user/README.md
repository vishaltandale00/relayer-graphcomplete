# Current-pointer-native simulated user

Product authority: user direction on 2026-10-09, PRD §13.2.3, ADR 0003 and ADR 0016. The simulated user observes displayed Current updates while work runs and may edit and explicitly Answer an ordinary root Input in the same running completion. Initial sealed input stays immutable. Acceptance means delivery; the provider owns consumption and waiting.

Actor prompt v9 / behavior v6 / observation v3 are available for explicit publication and promotion. Existing immutable actor revisions and evaluator releases retain their original behavior. No existing profile is automatically migrated.

## Build provenance and limits

This slice changes Rust core/server/app source. The existing private SSD compiler-object cache is reused; required source compilation and tests still run. The cache audit rejected a hosted Linux-X64 bundle on this macOS-ARM64 host and an incompatible local Ladybug manifest. No incompatible native bundle is restored, no Ladybug recipe or Cargo.lock changes, and LBUG library/include overrides remain unset. The existing Prime installation had an older recipe seal and was not adopted. Fresh preparation used the installer's exact reviewed, hash-checked uv/Python/wheel artifacts and the reviewed repository JavaScript closure. Temporary files and the exact checkout-pinned Playwright Chromium are on SSD.

Latest-state perception may miss revisions; gaps and capture exhaustion are explicit. Staged values are not delivery. Questions on semantic children, human Invoke roots, imported graphs or Invoke-bound actions are unavailable in this slice. A receipt does not prove the candidate incorporated the answer. The observer opens after initial dispatch, so initial latency is unsuitable for responsiveness comparisons. The annotation capture receipt retains the actual capture-time binary hashes. Later rebuilds differ; no identity with final runtime binaries is claimed. Its renderer, capture-script, durable-occurrence and four PNG hashes remain bound and verified. Current-built browser/input proof separately covers runtime integration. No calibrated coherence score, full trajectory coverage, paid-model realism, TTFG improvement or release is claimed.
