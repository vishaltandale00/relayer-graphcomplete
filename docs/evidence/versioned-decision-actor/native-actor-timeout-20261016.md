The user requested fixing the browser gate and making PR #755 ready for review. ## Diagnosis and correction

The original full browser failure reproduced in an isolated native journey, then with its unrelated adversarial preflight removed. After Invoke, the service expected child turn 3/attempt 3 while the page correctly retained source turn 2/attempt 2. The production readiness gate could never match. A two-second in-process regression at TaskActorService/HumanTaskService reproduced the same wrong identity.

Correcting the source identity exposed a second race in the previously unreached calibration rerun: child execution had settled, but the fresh source page still displayed Running. An accepted source alone cannot certify that its invocation state has refreshed. A separate readiness regression went red on that stale running state.

The service now waits for the source turn/attempt, post-submission paint freshness, and the exact invoked action/result/child-attempt/status/outcome correlation. The workspace freezes a small call-metadata snapshot before asynchronous source rendering. It publishes that snapshot only after source controls are applied, and invalidates it when another render starts or the visible scope changes. The ordinary observer then publishes the applied snapshot after its existing two-frame capture. Newly fetched terminal status cannot bypass a pending asset mount. It reads call lifecycle metadata, never child graph contents. The projection is not added to the actor's screenshot/control observation or used for completion authority. Working observations retain their existing child-current visibility checks. Send and Retry retain their own destination/attempt semantics. Missing source or child records fail closed.

The browser fixture now explicitly selects the visible Updated task-system analysis control, verifies the exact child's Returned Layer and source breadcrumb, and retains three-completion admission. A reference path may retain the source turn identity while displaying the child's layer; the final-content assertion therefore binds the actual Returned Layer, instead of assuming automatic turn navigation. The journey grows from eight to nine ordinary actor actions. Its deadlines, adverse preflight, judge rejection/recovery and remaining assertions stay intact. The guided tutorial exception is unavailable in the Eval actor surface: it has no desktop tutorial lifecycle.
