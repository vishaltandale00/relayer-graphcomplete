# Triage labels

The engineering skills use five canonical triage roles. These map directly to labels in this repository’s GitHub issue tracker.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate and route the issue |
| `needs-info` | `needs-info` | More information is required before work can proceed |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human review, judgment, or action |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a canonical role, use the corresponding GitHub label from this table.
