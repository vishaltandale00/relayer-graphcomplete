# Roadmap

- Implement the Prime Agent runtime adapter.
- Support per-role model and thinking selection.
- Give each content owner an explicit graph scope.
- Run a separate self-assess child for every scope.
- Support accept, revise, gather evidence, decompose, and stop.
- Prove one nested content-owner cycle with deterministic tests.

- Add workspace search and code-grounding tools.
- Add three-to-eight child decomposition policy.
- Add cross-graph concept reuse and edge creation.
- Add uncertainty and placeholder handling.
- Add subtree acceptance and budget-aware stopping.

## 0.3: Product integration

- Add durable checkpoints and resume.
- Add draft graph event streaming.
- Add local completion for build-deeper interactions.
