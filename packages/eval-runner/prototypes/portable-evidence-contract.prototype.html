Throwaway logic prototype

Can every native runner produce the same trustworthy evidence?

This demo tests a portable adapter contract without standardizing how Cargo, Vitest, Python, Electron, platform canaries, model evaluation, or human review actually run. Every adapter emits only four canonical events: attempt started, test point observed, artifact referenced, and attempt completed.

Prototype verdict: native execution stays native. Thin adapters emit four replay-safe event types; one shared reducer validates order and authored mappings, preserves each binding attempt, recovers interrupted streams, and seals the same privacy-minimal attestation shape for deterministic, model, and human producers.
